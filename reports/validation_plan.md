# AOI 检测设备验证方案（练习稿）

> **性质说明**：这是面试练习用的方案模板，对象是一台假设的外观 AOI 设备。
> 文中所有数值目标均为 **「模拟目标」**，用来演示方案如何设计，**不是 Apple 或任何真实产线的实际标准**。
> 真实项目中，目标值要由质量、制造、设备和客户要求共同确定。

| 项目 | 内容 |
| --- | --- |
| 验证对象 | 某外观件表面 AOI 设备（假设，供应商新设备） |
| 版本 | 练习稿 v1 |
| 与本项目的关系 | 第 2、3 天的分析说明了"数据怎么发现问题"，本方案说明"设备怎么证明能上线" |

---

## 1. 验证目标

### 1.1 范围

| 问题 | 本方案的假设 |
| --- | --- |
| 检测什么产品 | 外观件表面（假设） |
| 检测哪些缺陷 | 划痕 scratch、凹陷 dent、污渍 stain、裂纹 crack |
| 设备输出 | **OK / NG**，附缺陷类型和缺陷分数（属性型输出为主；若同时输出缺陷尺寸，另做第 4 节的变量型分析） |
| 所处工序 | 终检前的外观检测工序 |
| 设备在流程中的角色 | 替代部分人工目检；NG 件仍进入人工复判 |

### 1.2 验收目标（模拟目标）

| 维度 | 指标 | 模拟目标 | 说明 |
| --- | --- | --- | --- |
| 检出能力 | 总体缺陷 Recall | ≥ 99%（95% 置信下限） | 见 3.1 的样本量要求 |
| 检出能力 | 严重缺陷（crack）漏检数 | 验证样本中 0 漏检 | 严重缺陷按"零容忍"设计，不用平均值掩盖 |
| 误报 | 良品误报率 FPR | ≤ 3%（95% 置信上限） | 误报影响人工复判量 |
| 重复性 | 同一样品重复判定一致率 | ≥ 95% | 同设备、同样品、多次盲测 |
| 一致性 | 与参考判定的 Kappa | ≥ 0.85 | 用 Kappa 而非单纯一致率，排除"碰巧一致" |
| 节拍 | 单件检测时间 | ≤ 假设节拍 | 以产线节拍要求为准 |
| 稳定性 | 连续试运行期间点检通过率 | 100% | 标准样品点检，见第 5 节 |
| 可靠性 | 设备可用率 | ≥ 98% | 含故障和非计划停机 |
| 追溯 | 检测记录完整率 | 100% | 图像、分数、判定、时间、设备、批次均可追溯 |

**这些目标要在验证开始前签核，验证结束后不能因为结果不理想而回头改目标。**

## 2. 样品准备

### 2.1 样品组成（模拟设计）

| 类别 | 数量 | 用途 |
| --- | ---: | --- |
| 典型良品 | ≥ 1,000 | 估计误报；覆盖不同批次、表面状态 |
| 典型缺陷（4 类 × 75） | 300 | 估计 Recall，每类 75 件，覆盖轻微到严重 |
| 边界样品（接近判定限度） | ≥ 100 | 检查判定边界附近是否稳定；也用于属性一致性分析 |
| 位置/姿态/光照变化 | 在上述样品中穿插 | 工件摆放在合理公差内偏移时判定是否稳定 |

### 2.2 为什么是这些数量

用零漏检反推所需缺陷样本量（95% 置信，单侧）：

| 想证明的 Recall 下限 | 零漏检所需缺陷样本数 |
| ---: | ---: |
| ≥ 90% | 29 |
| ≥ 95% | 59 |
| ≥ 99% | **299** |

- 300 件缺陷、**零漏检**，才能说 Recall 下限约 99.0%。
- 只漏 1 件，下限降到约 98.4%；漏 2 件，约 97.9%。**样本量决定了你能证明多少。**
- **每类只有 75 件**时，即使零漏检，每类 Recall 下限只能证明到约 96%。所以严重缺陷要么增加样本，要么在验收时单独说明"只证明了到什么程度"，并在试运行中继续积累。
- 良品误报：1,000 件良品观察到 20 次误报（2.0%），95% 置信上限约 2.9%，刚好满足 ≤ 3% 的目标；观察到 25 次（2.5%）则上限约 3.5%，不满足。

### 2.3 参考判定（Ground truth）

- 由**独立于被验证设备**的方法确认：至少 3 名资深检验员**盲评**，必要时辅以显微镜或量具；
- 判定结果取多数意见；**3 人有分歧的样品单独记录**，由质量工程师组织复议，记录分歧原因和最终依据；
- 争议样品不删除：它们恰好反映了设备和人在边界处的真实难度，单独统计；
- 样品编号后封存，记录取样批次、制作方式、保存条件；划痕类样品反复接触会磨损，需要定期复核参考判定是否变化。

### 2.4 常见陷阱

- **只拿 AOI 报警过的样品做样品池**：会产生选择偏差，高估设备能力。
- **缺陷样品都是明显缺陷**：设备在边界样品上的表现才是难点。
- **样品被反复使用**：磨损或污染会改变样品状态，验证结果失真。

## 3. 检测能力验证

### 3.1 方法

- 所有样品**随机排序、盲测**，不让设备供应商或操作员知道参考判定；
- 每件样品在**不同日期、不同班次**至少测 3 次，既得到检出能力，也得到重复性数据；
- 每次都完整记录：样品编号、设备输出（判定、类型、分数）、图像、时间、操作员、环境记录。

### 3.2 统计指标

| 指标 | 计算方式 | 备注 |
| --- | --- | --- |
| Recall | 检出缺陷 / 全部真实缺陷 | 给出**精确二项置信区间**，不只给点估计 |
| 分类型 Recall | 每类缺陷分别统计 | 严重缺陷单独列出 |
| 漏检清单 | 逐件列出漏检样品及其特征 | 用于根因分析（尺寸、位置、对比度等） |
| FPR | 误报良品 / 全部良品 | 同样给置信区间 |
| 边界样品判定 | 重复测试中判定翻转的比例 | 边界处不稳定要明确标出 |
| 缺陷分数分布 | 良品、缺陷、边界样品的分数分布 | 检查判定阈值是否落在分布重叠区 |

### 3.3 判定规则

- 漏检的严重缺陷：**无论总体指标如何，视为未通过**，需要根因分析和整改后重新验证；
- 总体 Recall 或 FPR 的置信限未达标：视为未通过，不能用"点估计达标"替代；
- 报告必须同时列出样本量和置信区间，让评审人知道结论有多确定。

## 4. 测量系统验证

先判断设备的输出类型，再选分析方法，**不能把所有输出都套 Gage R&R**。

### 4.1 若输出连续数值（如缺陷长度 mm、面积 mm²）：变量型分析

- **重复性（Repeatability）**：同一设备、同一样品、同一条件下重复测量的变化；
- **再现性（Reproducibility）**：变化条件（不同操作员装载、不同夹具、不同设备、不同班次）后结果的变化；
- 设计示例：10 件覆盖规格范围的样品 × 3 个条件 × 3 次重复，计算 %GRR（占公差或总变异的比例）；
- 常用判读（通用经验准则，非特定公司标准）：%GRR < 10% 通常可接受；10%–30% 视应用有条件接受；> 30% 通常不可接受；同时看可区分的类别数 ndc；
- **偏差与线性**：与参考量具比较，检查偏差是否随尺寸变化。

**相关性不等于一致性**：

| 样品 | 参考设备 | 新设备 | 差值 |
| --- | ---: | ---: | ---: |
| A | 1.0 | 1.5 | +0.5 |
| B | 2.0 | 2.5 | +0.5 |
| C | 3.0 | 3.5 | +0.5 |

两个设备的相关系数是 1，但新设备系统性偏高 0.5。所以要同时检查**相关性、偏差、差值分布（如 Bland-Altman）**，
并特别看规格边界附近的差值是否会造成不同的合格判定。

### 4.2 若输出 OK / NG 或缺陷类型：属性一致性分析

| 分析 | 回答的问题 | 指标 |
| --- | --- | --- |
| 设备内一致性 | 同一样品重复判定是否一致 | 重复判定一致率 |
| 设备 vs 参考 | 设备判定与参考判定是否一致 | Kappa、漏判率、误判率 |
| 操作员间一致性（若有人工环节） | 不同操作员的判断是否一致 | 操作员间 Kappa |
| 边界分析 | 边界样品是否更容易分歧 | 分歧样品占比及特征 |

- 样品设计要包含足够多的**边界样品**，只有明显好坏的样品会让一致性虚高；
- 样品数量按公司的 MSA 规范确定，上面的样品池（良品 + 缺陷 + 边界）可以复用。

### 4.3 稳定性与可靠性

- **稳定性**：今天、下周、不同班次、不同环境（温度、光照）下，同一标准样品的结果是否保持一致；
- **可靠性**：设备长期运行是否频繁故障，异常后能否恢复，故障频次和平均修复时间是多少。

## 5. 产线试运行

### 5.1 影子运行（Shadow mode）

先让 AOI **与现有流程并行**运行，AOI 的判定**不影响实际放行**，只做对比。这样可以在零质量风险下收集真实数据。

### 5.2 检查项目

| 项目 | 检查内容 |
| --- | --- |
| 班次与批次 | 不同班次、批次、产线的误报率和检出表现是否一致 |
| 节拍 | 实际检测节拍是否满足产线要求，含上下料和图像处理时间 |
| 故障与停机 | 故障次数、原因、平均修复时间、可用率 |
| 人工复判负载 | AOI 报警带来的人工复判量，是否在可承受范围内 |
| 数据追溯 | 图像、判定、分数、批次是否完整保存且可查询 |

### 5.3 漏检的独立估计

产线上 AOI 判 OK 的产品通常**没有后续检查**，所以无法直接知道漏检数。需要设计独立抽检：

- 对 AOI 判 OK 的产品**随机抽样**，用独立方法（高倍检查、人工全面复检）判定；
- 记录抽样率、样本量，用置信区间报告漏检率上界；
- **不要用"没有客诉"代替漏检评估**：客诉滞后，且不是所有缺陷都会被发现。

### 5.4 稳定性监控方法

- 每班开始和中间用**标准样品（金样品，含良品、缺陷和边界样品）**点检，结果必须与参考一致；
- 对关键指标做控制图：报警率、复判确认的误报占比、缺陷分数均值；
- 监控图像特征（亮度、对比度）的漂移。**本项目的模拟数据里，M03 在周三后半天亮度持续下降、误报率上升，就是这种漂移，
  标准样品点检和亮度控制图可以更早发现它。**

## 6. 上线与监控

### 6.1 验收与签核

| 角色 | 职责 |
| --- | --- |
| 质量工程 | 验证方案、统计分析、验收结论 |
| 制造工程 / 产线 | 节拍、操作性、复判负载 |
| 设备工程 | 设备可靠性、维护方案、校准 |
| 供应商 | 技术支持，整改责任 |
| 项目负责人 | 最终签核 |

- 签核条件：第 1.2 节所有目标满足，或对未满足项有记录在案的**风险接受决定**（含负责人和期限）。

### 6.2 上线节奏

1. 影子运行 → 2. 单条产线小范围试点（AOI 判定生效，保留人工抽检）→ 3. 逐步扩展 → 4. 常态化监控。

### 6.3 回退方案

触发条件示例（模拟）：

- 标准样品点检出现漏检；
- 控制图连续异常（如报警率或误报占比超出控制限）；
- 设备故障或图像质量异常。

触发后：**立即回退到原有人工检验流程**，并启动根因分析；恢复前必须重新通过标准样品验证。

### 6.4 持续监控与变更管理

- 看板：报警率、复判误报占比、标准样品点检、图像特征分布、放行比例、设备状态；
- 校准与维护周期（光源寿命、镜头清洁、相机标定）；
- **变更管理**：检测规则、阈值、模型版本、光源或相机参数的任何改动，都要评估影响，必要时重新验证；
- 若使用复判模型：上线前要在独立数据上验证，上线后监控输入分布和放行比例，
  出现漂移（如本项目 Notebook 03 中反光批次的情况）时回退到全部人工复判，重新验证后再恢复。

## 7. 主要风险与假设

| 风险 | 影响 | 缓解措施 |
| --- | --- | --- |
| 样品不能代表量产变化 | 验证结论被高估 | 样品覆盖多批次、多表面状态；试运行继续验证 |
| 参考判定本身有分歧 | 指标不可靠 | 多人盲评，分歧样品单独记录，必要时用仪器确认 |
| 缺陷样本数量有限 | 置信区间宽 | 明确说明证明到什么程度；试运行继续积累 |
| 设备状态漂移 | 误报或漏检上升 | 标准样品点检、控制图、维护计划 |
| 来料或工艺变化 | 现有阈值不再适用 | 变更管理，变更后重新评估 |
| 供应商只提供汇总指标 | 无法复现和审核 | 要求提供原始数据、样品清单和测试条件 |

## 8. 验证流程总览

```text
目标与验收标准签核
        ↓
样品准备 + 参考判定
        ↓
检测能力验证（盲测、重复）
        ↓
测量系统验证（GRR / 属性一致性）
        ↓
影子运行（节拍、稳定性、漏检抽检）
        ↓
小范围试点（人工抽检保留）
        ↓
签核上线 + 持续监控 + 变更管理
```
