**LogisticRegression（逻辑回归）**虽然名字里带有“回归”，但它实际上是一种**经典的监督学习分类模型**，主要用于解决**二分类问题**（如判断邮件是否为垃圾邮件、用户是否会流失），也可以通过扩展解决**多分类问题**。

它的核心思想是：**先用线性回归计算出一个连续的分数，再通过一个非线性函数（Sigmoid 函数）把这个分数压缩到 $(0, 1)$ 区间内，从而将其解释为“属于某一类的概率”。**

---

### 核心工作原理

逻辑回归的预测过程分为两步：

1. **线性加权求和：**
   将输入特征 $x_1, x_2, \dots, x_n$ 与对应的权重 $w_1, w_2, \dots, w_n$ 相乘并加上偏置项 $b$，得到一个线性得分 $z$：

$$z = w_1x_1 + w_2x_2 + \dots + w_nx_n + b = \mathbf{w}^T\mathbf{x} + b$$

2. **概率映射（Sigmoid 激活）：**
   由于 $z$ 的取值范围是 $(-\infty, +\infty)$，无法直接作为概率使用。逻辑回归将其代入 **Sigmoid 函数**，把结果映射到 $(0, 1)$ 之间：

$$\hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}}$$

- 当 $z$ 很大时，$\hat{y}$ 趋近于 $1$（判定为正类）。
- 当 $z$ 很小时，$\hat{y}$ 趋近于 $0$（判定为负类）。
- 通常以 **0.5** 为阈值：$\hat{y} \ge 0.5$ 预测为 $1$，$\hat{y} < 0.5$ 预测为 $0$。

---

### 核心特点与优缺点

| 维度               | 具体表现                                                                                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **可解释性极强**   | 每个特征的权重 $w_i$ 直接反映了该特征对正类概率的影响方向（正/负相关）和重要程度，在金融风控、医疗诊断等强合规领域备受青睐。                         |
| **输出概率校准好** | 不仅能给出分类结果，还能给出置信度（概率值），便于业务侧根据成本调整分类阈值（如风控场景中把阈值从 0.5 降到 0.3 以提高召回率）。                     |
| **训练与推理极快** | 计算复杂度低，对内存占用小，非常适合作为工业界建模的基线模型（Baseline）或处理大规模稀疏特征（如 CTR 点击率预估）。                                  |
| **主要局限性**     | 本质上是一个**线性分类器**（决策边界是直线或超平面），无法直接捕捉特征之间的复杂非线性关系，通常需要依赖人工特征工程（如特征交叉、分箱）来提升上限。 |

---

### 常见变体与扩展

- **多项逻辑回归（Multinomial / Softmax Regression）：** 将 Sigmoid 替换为 Softmax 函数，使模型能够直接处理多分类任务（如手写数字 0–9 识别）。
- **正则化逻辑回归（L1 / L2 正则）：** 在损失函数（交叉熵损失）中加入 L1（Lasso，可产生稀疏权重用于特征选择）或 L2（Ridge，防止过拟合）惩罚项，这也是 `scikit-learn` 等主流库中的默认配置。
